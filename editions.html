READ THIS FIRST

Five different things

The most common misreading of GTA VI's store page is treating an edition, a physical format, an upgrade, a pre-order bonus and a collector box as the same category. They are not. Each has a different owner, a different purchase moment and a different lifetime.

ULTIMATE EDITION CONTENT

What Ultimate actually adds

Rockstar's own wording is that these bonuses are threaded across all aspects of Jason and Lucia's story, with new items uncovered behind each chapter. They are therefore not all available at launch. The full documented list is reproduced below rather than summarised as "extra cars and weapons".

UPGRADE — NOT AN EDITION

Ultimate Edition Upgrade

The upgrade is a separately purchasable add-on. It is not a third edition, not a bundle, and it does not include the base game — the platform listings state the game is required to access this content and is sold separately.

PURCHASE FORMAT

Digital and Code-in-Box

A format describes how the product reaches you. It is not an edition, and in GTA VI's case the distinction matters more than usual: the physical product contains no disc.
